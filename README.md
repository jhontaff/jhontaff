### 🚀 Currently building: [Align](https://alignassistant.com/)

A personal productivity assistant (tasks, finances, habits, calendar) with a conversational AI agent that acts on those domains through **tool calling**. Live in production.

- **Backend** → [align-api](https://github.com/jhontaff/align-api): Java 21, Spring Boot 3.5, PostgreSQL + Flyway, JWT, Gemini behind a provider-neutral LLM layer, Web Push, Testcontainers. 26 architecture decision records in `docs/decisions/`.
- **Frontend** → [align-web](https://github.com/jhontaff/align-web): Angular 20, installable PWA with push notifications.
- **Ops** → self-hosted on a VPS: systemd + Docker + Nginx Proxy Manager, CI/CD with GitHub Actions, health-checked deploys with automatic rollback.
